## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-04-01 | T | vehicles:getReport IPC | mitigate | Validate period against allow-list (daily/weekly/monthly/yearly) and normalize selectedDate to YYYY-MM-DD before SQL use. |
| T-04-02 | I | report query response | mitigate | Select only required reporting columns from psm_vehicles and avoid exposing internal fields not needed by UI. |
| T-04-03 | D | report query execution | accept | Dataset is local single-site SQLite and period windows are bounded (max 365 days), low DoS risk for this deployment model. |
